# iPhone, iPad, Mac and Windows apps

Pikibun's apps are the Native Shell client ([`apps/nsh`](../apps/nsh/README.md)), the same client the web serves, packaged for each platform by `app-v` releases: a Windows installer and portable zip (x64), the macOS app (Apple silicon), Linux (x86_64), Android, and iOS through TestFlight. They are previews: each `app-v` release is a GitHub prerelease. The earlier Electron Mac and Windows app is removed; its last `desktop-v` release was its last.

- **Every platform** has the web client's pages: sign-in, the sidebar and Sessions, a new session, a session with its panel, share and invite links, and Settings. The native builds sign in to a server you enter, with GitHub in the app's own window or, where the server allows it, a username and password; each such sign-in is listed under **Settings → Profile → Signed-in apps**. New password accounts are made on the web.
- **This Mac** (This Computer on Windows and Linux), under **Settings**, makes the computer one of your hosts for the server you're signed in to: it pairs it in one step, starts and stops its host (with the same consent as `--unsafe-no-sandbox` where there is no sandbox; on macOS, **None** or **macOS sandbox**), chooses its models, signs Pi in to a provider, and lists what the computer lacks with how to get it. The app runs the `pikibun` command for it (from npm: when it's missing or too old, the page's **Install pikibun** button installs it into the app's own folder with your Node.js, with no sudo or PATH change; a `pikibun` installed with `npm install -g` runs where the app has none), with `pikibun connect`'s state, so a computer paired from a terminal carries over, and only one of the two runs at a time. Hosting lasts while the app is open. See [This Computer](../apps/nsh/README.md#this-computer).
- **Files**: the desktop builds attach any file dropped on the chat box or pasted from a file manager; iPhone and Android pick photos.

The web client can [notify you](notifications.md) when a session waits for an approval, finishes or fails; the native builds don't show notifications yet, but manage your preferences and devices under **Settings → Notifications**.
