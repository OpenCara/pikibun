Only this computer can reach it, and only your GitHub account can sign in. Pikibun signs you in with GitHub through an OAuth app of your own. Register one once at https://github.com/settings/applications/new with the homepage http://127.0.0.1 and the authorization callback URL http://127.0.0.1/api/auth/github/callback, generate a client secret, and enter both here.

A full Pikibun server for your team, from the same data: people sign in, create workspaces, and pair their own machines with pikibun connect or this app. It serves plain HTTP on this computer; people reach it at a public HTTPS address through a TLS proxy or tunnel you run, such as tailscale serve, Cloudflare Tunnel or Caddy, which forwards to the address below.

One per line: a GitHub login (the app looks up its user ID), github:12345 or password:alice. They see every account and host, can always sign up, and the first one with an account owns this computer's host.

GitHub sign-in needs an OAuth app of its own for the public address, with the authorization callback URL https://…/api/auth/github/callback. Leave these empty with usernames and passwords only.
